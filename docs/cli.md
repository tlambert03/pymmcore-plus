# CLI Reference

This page provides documentation for the `mmcore` command line tool, which is
installed along with `pymmcore-plus`.

The CLI can be used to interact with the `pymmcore_plus` package from the command line,
including the installation, removal, and selection of Micro-Manager device
adapters, showing log files, and running a test acquisition (`mmcore run`, which
doesn't save anything).  (The default `--dest` folder for `install` and
`build-dev` depends on your platform; see
[Micro-Manager device adapters](install.md#installing-micro-manager-device-adapters).)
